Proposition III.34 — Cutting Off a Segment Containing a Given Angle
===================================================================

.. rubric:: Book III, Proposition XXXIV. Problem (*Pickering p. 119*)

To cut off from a given circle :byrne-circle:`blue` a segment which shall contain an angle equal to a given angle :byrne-angle:`red`.
