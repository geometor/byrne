Proposition III.3 — Diameter Bisects a Chord Perpendicularly
============================================================

.. rubric:: Book III, Proposition III. Theorem (*Pickering p. 76*)

If a straight line (:byrne-line:`black solid`) drawn through the centre of a circle :byrne-circle:`blue` bisects a chord ((solid red + dotted red line)) which does not pass through the centre, it is perpendicular to it; or, if perpendicular to it, it bisects it.
