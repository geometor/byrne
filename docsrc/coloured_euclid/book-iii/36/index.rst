Proposition III.36 — Tangent-Secant Power of a Point
====================================================

.. rubric:: Book III, Proposition XXXVI. Theorem (*Pickering p. 121* · ``G.201``)

*If from a point without a circle two straight lines be drawn to it, one of which* :byrne-line:`blue solid <iii36:/ D T />` *is a tangent to the circle, and the other* (:byrne-line:`black solid <iii36:/ O A />` + :byrne-line:`red dotted <iii36:/ C O />` + :byrne-line:`red solid <iii36:/ D C />`) *cuts it; the rectangle under the whole cutting line and the external segment* :byrne-line:`red solid <iii36:/ D C />` *is equal to the square of the tangent* :byrne-line:`blue solid <iii36:/ D T />`.

.. picture:: /_static/figures/iii36.svg
   :alt: Book III Proposition 36 — External blue tangent and red-black secant through the center of a black circle.
   :caption: **Book III, Prop. XXXVI (p. 121 · G.201).** Square on tangent :byrne-line:`blue solid <iii36:/ D T />` equals the rectangle contained by whole secant and external part :byrne-line:`red solid <iii36:/ D C />`.

.. container:: byrne-eq-block

   **Demonstration (Case I: Secant through the centre, :just:`III.18`, :just:`I.47`, :just:`II.6`).**

   Draw radius :byrne-line:`yellow solid <iii36:/ O T />` from the centre to the point of contact; then :byrne-angle:`yellow <iii36:< D T O )>` = :byrne-op:`right-angle` (:just:`III.18`).

   :byrne-line:`blue solid squared <iii36:/ D T />` = (:byrne-line:`red dotted <iii36:/ C O />` + :byrne-line:`red solid <iii36:/ D C />`)² − :byrne-line:`yellow solid squared <iii36:/ O T />` (:just:`I.47`),

   or, since radii :byrne-line:`yellow solid <iii36:/ O T />` = :byrne-line:`red dotted <iii36:/ C O />` = :byrne-line:`black solid <iii36:/ O A />`,

   :byrne-line:`blue solid squared <iii36:/ D T />` = (:byrne-line:`red dotted <iii36:/ C O />` + :byrne-line:`red solid <iii36:/ D C />`)² − :byrne-line:`red dotted squared <iii36:/ C O />`,

   :byrne-op:`therefore` :byrne-line:`blue solid squared <iii36:/ D T />` = (:byrne-line:`black solid <iii36:/ O A />` + :byrne-line:`red dotted <iii36:/ C O />` + :byrne-line:`red solid <iii36:/ D C />`) :byrne-op:`rect-by` :byrne-line:`red solid <iii36:/ D C />` (:just:`II.6`). **Q.E.D.**
