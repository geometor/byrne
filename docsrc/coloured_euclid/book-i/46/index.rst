Proposition I.46 — Construction of the Square
=============================================

.. rubric:: Book I, Proposition XLVI. Problem (*Pickering p. 47* · ``G.139``)

*Upon a given straight line* (:byrne-line:`black solid <i46:/ A B />`) *to construct a square.*

.. picture:: /_static/figures/i46.svg
   :alt: Book I Proposition 46 — Construction of a square with black, blue, red, and yellow sides and four colored right-angle quadrants.
   :caption: **Book I, Prop. XLVI (p. 47 · G.139).** Construction of the square on :byrne-line:`black solid <i46:/ A B />` with four distinct side and corner registers.

.. picture:: 0081.g1.png
   :alt: Oliver Byrne 1847 Pickering archival full-RGB plate for Proposition I.46 (Leaf 81).
   :caption: **1847 Chiswick Press Archival Plate (Leaf 81, p. 47).** Full-RGB reproduction of Byrne's four-color woodblock print.

.. container:: byrne-eq-block

   **Construction.** Draw :byrne-line:`blue solid <i46:/ A C />` :byrne-op:`perp` and ``=`` :byrne-line:`black solid <i46:/ A B />` (:just:`I.11`, :just:`I.3`). Draw :byrne-line:`red solid <i46:/ C D />` :byrne-op:`parallel` :byrne-line:`black solid <i46:/ A B />`, meeting :byrne-line:`yellow solid <i46:/ B D />` drawn :byrne-op:`parallel` :byrne-line:`blue solid <i46:/ A C />` (:just:`I.31`).

   **Demonstration.**

   In parallelogram :byrne-sq:`yellow outline <i46:< A B D C >>`, :byrne-line:`blue solid <i46:/ A C />` = :byrne-line:`black solid <i46:/ A B />` (const.), and opposite sides of a parallelogram are equal (:just:`I.34`), so all four sides (:byrne-line:`black solid <i46:/ A B />`, :byrne-line:`blue solid <i46:/ A C />`, :byrne-line:`red solid <i46:/ C D />`, :byrne-line:`yellow solid <i46:/ B D />`) are equal.

   Again, :byrne-angle:`yellow <i46:< B A C )>` = :byrne-op:`right-angle` (const.); since :byrne-line:`black solid <i46:/ A B />` meets parallels :byrne-line:`blue solid <i46:/ A C />` and :byrne-line:`yellow solid <i46:/ B D />`, :byrne-angle:`yellow <i46:< B A C )>` + :byrne-angle:`red <i46:< D B A )>` = :byrne-op:`two-right-angles` (:just:`I.29`),

   :byrne-op:`therefore` :byrne-angle:`red <i46:< D B A )>` = :byrne-angle:`yellow <i46:< B A C )>` = :byrne-op:`right-angle`, and opposite angles :byrne-angle:`black <i46:< A C D )>` and :byrne-angle:`blue <i46:< C D B )>` are likewise right (:just:`I.34`).

   :byrne-op:`therefore` :byrne-sq:`yellow outline <i46:< A B D C >>` is a square (Simson Def. XXVII / :just:`I.def.22`). **Q.E.F.**
