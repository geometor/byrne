Proposition I.32 — Exterior Angle & Angle Sum of a Triangle
===========================================================

.. rubric:: Book I, Proposition XXXII. Theorem (*Pickering p. 33* · ``G.125``)

*If any side* (:byrne-line:`red solid-dotted <i32:/ B C /; / C D />`) *of a triangle be produced, the external angle* (:byrne-angle:`red+black <i32:< E C A ); < D C E )>`) *is equal to the sum of the two internal and opposite angles* (:byrne-angle:`blue <i32:< B A C )>` *and* :byrne-angle:`yellow <i32:< C B A )>`), *and the three internal angles of every triangle taken together are equal to two right angles.*

.. picture:: /_static/figures/i32.svg
   :alt: Book I Proposition 32 — Triangle with parallel blue auxiliary line splitting the exterior angle into alternate and corresponding components.
   :caption: **Book I, Prop. XXXII (p. 33 · G.125).** Parallel line :byrne-line:`blue solid <i32:/ C E />` transports both remote interior angles into the exterior angle.

.. container:: byrne-eq-block

   **Construction.** Through the right base vertex draw :byrne-line:`blue solid <i32:/ C E />` :byrne-op:`parallel` :byrne-line:`black solid <i32:/ B A />` (:just:`I.31`).

   **Demonstration.**

   Then :byrne-angle:`red <i32:< E C A )>` = :byrne-angle:`blue <i32:< B A C )>` (alternate, :just:`I.29`), and :byrne-angle:`black <i32:< D C E )>` = :byrne-angle:`yellow <i32:< C B A )>` (corresponding, :just:`I.29`),

   :byrne-op:`therefore` :byrne-angle:`blue <i32:< B A C )>` + :byrne-angle:`yellow <i32:< C B A )>` = :byrne-angle:`red <i32:< E C A )>` + :byrne-angle:`black <i32:< D C E )>` (:just:`C.N.2`),

   and therefore adding the third interior angle :byrne-angle:`black <i32:< A C B )>`:

   :byrne-angle:`yellow <i32:< C B A )>` + :byrne-angle:`blue <i32:< B A C )>` + :byrne-angle:`black <i32:< A C B )>` = (:byrne-angle:`red <i32:< E C A )>` + :byrne-angle:`black <i32:< D C E )>` + :byrne-angle:`black <i32:< A C B )>`) = :byrne-op:`two-right-angles` (:just:`I.13`). **Q.E.D.**
