Proposition IV.10 — Isosceles Golden Triangle
=============================================

.. rubric:: Book IV, Proposition X. Problem (*Pickering p. 135* · ``G.223``)

*To construct an isosceles triangle, in which each of the angles at the base shall be double of the vertical angle.*

.. picture:: /_static/figures/iv10.svg
   :alt: Book IV Proposition 10 — Construction of the 36-72-72 degree Golden Triangle via red and blue circles.
   :caption: **Book IV, Prop. X (pp. 135–136 · G.223).** The :math:`36^\circ\text{–}72^\circ\text{–}72^\circ` Golden Triangle uniting :ref:`II.11 <byrne-ii-11>` and ``III.37``.

.. picture:: 0169.g1.png
   :alt: Oliver Byrne 1847 Pickering archival full-RGB plate for Proposition IV.10 (Leaf 169).
   :caption: **1847 Chiswick Press Archival Plate (Leaf 169, p. 135).** Full-RGB reproduction of Byrne's four-color woodblock print.

.. container:: byrne-eq-block

   **Construction.** Take any straight line (:byrne-line:`black solid <iv10:/ A C />` + :byrne-line:`black dotted <iv10:/ C B />`) and divide it so that whole :byrne-op:`rect-by` :byrne-line:`black dotted <iv10:/ C B />` = :byrne-line:`black solid squared <iv10:/ A C />` (:just:`II.11`). With the whole line as radius describe :byrne-circle:`red <iv10:( A B )>`, place chord :byrne-line:`blue solid <iv10:/ B D />` = :byrne-line:`black solid <iv10:/ A C />` in it (:just:`IV.1`), draw second leg :byrne-line:`yellow solid <iv10:/ A D />`, join :byrne-line:`red solid <iv10:/ C D />`, and circumscribe :byrne-circle:`blue <iv10:( P A )>` about triangle :math:`ACD` (:just:`IV.5`).

.. folio:: 0170
   :page: 136

.. container:: byrne-eq-block

   **Demonstration (:just:`III.37`, :just:`III.32`, :just:`I.32`, :just:`I.6`, :just:`I.5`).**

   Since whole radius :byrne-op:`rect-by` :byrne-line:`black dotted <iv10:/ C B />` = :byrne-line:`black solid squared <iv10:/ A C />` = :byrne-line:`blue solid squared <iv10:/ B D />`, chord :byrne-line:`blue solid <iv10:/ B D />` is tangent to :byrne-circle:`blue <iv10:( P A )>` (:just:`III.37`).

   :byrne-op:`therefore` tangent-chord angle :byrne-angle:`yellow <iv10:< C D B )>` = alternate inscribed apex angle :byrne-angle:`red <iv10:< B A D )>` (:just:`III.32`).

   Adding :byrne-angle:`black <iv10:< C D A )>` to each and applying :just:`I.5` + :just:`I.32` proves :byrne-line:`red solid <iv10:/ C D />` = :byrne-line:`blue solid <iv10:/ B D />` = :byrne-line:`black solid <iv10:/ A C />` (:just:`I.6`),

   :byrne-op:`therefore` each base angle :byrne-angle:`blue <iv10:< D B A )>` = twice the vertical angle :byrne-angle:`red <iv10:< B A D )>`. **Q.E.F.**
