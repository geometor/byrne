Corrigenda — Faults to Be Corrected
===================================

.. rubric:: Pickering 1847 Errata List (p. xxix, Leaf 33)

On the final preliminary recto (**p. xxix, Leaf 33**, signature ``f``), Byrne lists eleven press corrections under the heading *Faults to be corrected before reading this Volume*:

1. **Page 13, line 9:** for ``def. 7`` read ``def. 10``.
2. **Page 45, last line:** for ``pr. 19`` read ``pr. 29``.
3. **Page 54, line 4 from the bottom:** for *black and red line* read *blue and red line*.
4. **Page 59, line 4:** for *add black line squared* read *add blue line squared*.
5. **Page 60, line 17:** for *red line multiplied by red and yellow line* read *red line multiplied by red, blue, and yellow line*.
6. **Page 76, line 11:** for ``def. 7`` read ``def. 10``.
7. **Page 81, line 10:** for *take black line* read *take blue line*.
8. **Page 105, line 11:** for *yellow black angle add blue angle equal red angle* read *yellow black angle add blue angle add red angle*.
9. **Page 129, last line:** for *circle* read *triangle*.
10. **Page 141, line 1:** for *Draw black line* read *Draw blue line*.
11. **Page 196, line 3:** before the yellow magnitude insert ``M``.
