geometor.byrne.render¶

Interactive .euclid-graphic SVG renderer for Oliver Byrne (1847) symbolic plates.

Exports crisp pixel-space SVGs directly from ByrnePlate models while satisfying both:

  1. Standalone SVG fidelity (embedded <style> sheet using --byrne-* Chiswick Press colors for light and dark themes), and

  2. PHOTON Publish interactive codex contract (svg.euclid-graphic, <defs> #geom-tick-1..3, #elements / #graphics / #highlights / #points / #labels, 3-vertex midpoint <path> segments, .geom-ang-arc overlays, data-ref, data-aliases, and data-byrne-color).
