geometor.byrne.sphinx_ext¶

Self-contained Sphinx extension for Oliver Byrne’s 1847 inline visual glyph roles.

Registers nine inline RST roles without modifying photon-platform/publish:

  • :byrne-line: — Colored/styled straight line segment (supports solid, dashed, dotted, solid-dotted, orientations, and squared / ^2).

  • :byrne-angle: — Colored wedge sector (single color or split composite such as yellow+black or blue+yellow).

  • :byrne-tri: — Colored triangle (filled red filled or 3-side colored red/blue/black).

  • :byrne-sq: — Colored square (filled, outline, or half diagonal).

  • :byrne-rect: — Colored rectangle (filled or outline).

  • :byrne-arc: — Colored circular arc.

  • :byrne-circle: — Colored full circle.

  • :byrne-mag: — Book V Eudoxian abstract magnitude symbols (red circle, yellow square, blue diamond, black shield, red pentagon).

  • :byrne-op: — Byrne’s 1847 formal typographic and geometric operators (right-angle, two-right-angles, gt / ⊏, lt / ⊐, therefore / ∴, because / ∵, parallel / ∥, perp / ⊥, prop / ::, rect-by / ×).

Every geometric role accepts an optional <plate_id:geom_expr> target in angle brackets (for example :byrne-sq:`black filled <i47:< A B F G >>`), emitting a <span class="byrne-token geom-ref" data-ref="..."> wrapper around an inline <svg class="byrne-glyph"> micro-glyph so both geometor_interactive.js and byrne_interactive.js highlight bidirectionally on hover and click.
