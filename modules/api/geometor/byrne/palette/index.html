geometor.byrne.palette¶

Authentic 1847 Chiswick Press four-color palette and stroke grammar for Oliver Byrne’s Euclid.

Calibrated directly against the 1847 William Pickering / Charles Whittingham (Chiswick Press) woodblock color plates (Internet Archive firstsixbooksofe00eucl), with theme-adaptive CSS custom properties so all four primary inks—Red, Blue, Yellow, and Black—remain legible on both warm rag-paper light themes and modern dark themes.

class geometor.byrne.palette.ByrneColorSpec¶

Color specification for one of Oliver Byrne’s four 1847 woodblock inks.

Stores canonical token name, human-readable label, light/dark stroke and fill hex values (light_hex, dark_hex, light_fill_hex, dark_fill_hex), CSS custom property tokens (css_var, css_fill_var), and the 1847 Chiswick Press historical_pigment note.
